## 2. 第一卷补充与结构核对

第一卷原项目已有第 1–4 章及第 1 章附录。核对得到，正文中的原书页码标记覆盖第一卷 1–186 页；第二卷覆盖 1–198 页。合并稿有 7 章、44 个编号节和第 1 章附录，章节编号保持原书体系。

本次第一卷最主要的补录是原先遗漏的完整参考文献表：**132 条文献、101 个作者组**。第二卷保留 **78 条文献、62 个作者组**。合计 **210 个带卷号的文献条目**，其中可能包含两卷共同引用的著作，不表示 210 部互不重复的著作。

另外补入/合并出版资料和相关前后附文；保留两卷各自的序言及第一卷符号说明，重复的出版社系列目录只保留一份。目录和页码不沿用原书静态数字。

这里的页码覆盖核对是**结构检查**，不是声称所有正文已重新逐字转写、每个公式和证明均完成独立数学复核。没有为了“补全”而自行写入原书不存在的章节、证明或材料。详细结构记录见 `source-structure-coverage.json`。

## 3. 引用与跳转

为 **313 个编号陈述**建立目标，为章、节、图和 **34 个带标记的公式**建立相应目标。处理记录中有 540 处编号陈述/章/节交叉引用、390 处文献引用，以及 15 处能够明确消歧的公式文本引用；另有图号等链接。引文和链接保留原书的编号显示，不用新的简写符号替换数学记号。

参考文献采用原生 `\cite` / `\bibitem`，两卷文献表分开保留原作者编号。这样避免同一作者的 `[1]` 因合并而链接到另一卷的不同著作。

针对明显的编号错误，依据具体上下文重新定位，例如 Definition 1.4.4 改指 Definition 1.5.1、Theorem 3.15.3 改指 Theorem 3.5.13，以及若干“定理/引理/推论”类别误称。完整改动记录在 `type-reference-corrections.json`，原显示和目标见其他引用审计文件。

**保留的一处不确定引用：**第二卷原书第 115 页，在构造三维交换图、讨论连接同态的段落中写作 “the proof of Theorem 6.3.13”。现有编号 6.3.13 是一个引理，其内容不足以确认就是此处所指。该处保留原书文字，不强行链接到这个引理。详见 `unresolved-source-references.json`。这与 LaTeX 的未定义引用不同：最后的编译没有 `??` 型未定义引用。

原书指向拟议第 8–12 章的引用保留为普通文本，不生成虚构的章节目标。

## 4. 原生索引

第二卷附的是两卷合并索引，原说明以斜体页码表示第一卷。现有转写丢失了部分斜体，并夹杂少量页码和词条错误，因此不能直接把这些数字复制到合并稿末尾。

本次为原索引的 **661 处页码引用**建立了正文定位，使用 `\IndexMark` / `\index` 插入正文，通过 makeindex 排序、合并重复页码、生成层级和 `see` / `see also` 条目。另有 **9 个 see 和 1 个 see also** 条目；makeindex 最终接受 671 条输入，拒绝 0 条，警告 0 条。

定位以原卷页、术语及附近正文为基础进行匹配，对低置信度、跨页、卷号混淆和语义易混淆的项目重点人工复核。其中 **22 处原索引卷页定位发生修正**，另有拼写、排序键和层级整理。几个代表性修正如下：

| 词条 | 原转写/原索引定位 | 复核定位 |
| --- | --- | --- |
| Cocycle condition | II:26 | I:26 |
| First Chern class | II:177 | II:117 |
| Nullstellensatz | I:112 | I:121 |
| Osgood's theorem | I:62 | I:52 |

表中 `I:26` 表示第一卷原书印刷页码 26，不是本次 PDF 第 26 页。全部 661 处的原定位、修正定位、上下文及新页码见 `index-page-map.csv`。

“Canonical bundle” 在第一卷 Grassmannian 附近指 universal bundle，已与第二卷的典范线丛含义分开作为子条目；将几种正合性统一归入 `Exactness`，避免把 de Rham 正合性错排成 Dolbeault 正合性的下位概念。部分明显人名拼写错误和不影响术语含义的排字错误也已整理。

**页码跳转另做了实际验证。** 合并稿有前附文，PDF 物理页与正文逻辑页并不相同。修正了页锚点设置，防止索引“99”错误地跳向 PDF 第 99 页。最终逐一检查了 644 个逻辑页码链接，全部到达其显示数字对应的正文页码，错位 0 个。

这些定位与匹配记录使索引修订可追溯；它不等于对每一个索引概念的数学内容重新论证。

检查了全文版面缩略图，并放大检查交换图、目录、索引和修改处；同时用 MuPDF 和 Poppler 检查了代表性的渲染效果。检查不能保证原书或既有转写中不存在尚未识别的数学/文字错误。本次没有对所有证明逐一进行独立数学验证。

机器可读结果见 `build-validation.json`。这些页码、链接数量和哈希值对应本次交付；之后编辑正文并重新编译时，原生索引会更新，而该审计快照不会自动覆盖。
